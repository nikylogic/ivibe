# Muse Code log

I used Meta's Muse Code while building iVibe, alongside the Meta models that run inside the product. This log records what it was used for, so Meta's tooling can be seen in how the project was made.

| Use               | What Muse Code did                                                                                                                                                                                    |
| ----------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Coding            | Writing and changing iVibe's code during the build                                                                                                                                                    |
| Planning          | Working through the plan and the approach before building                                                                                                                                             |
| Automated testing | Running and checking automated tests                                                                                                                                                                  |
| Product testing   | iVibe pastes into Muse Code as a target app, with screenshots as real images ([`targets.ts`](../packages/engine/src/targets.ts)). In the demo video, Muse Code fixes the demo bug from iVibe's prompt |
